# 分板块调研计划

本文件是设计阶段的研究路线。每一块调研完成后，必须把“可迁移原则、不能泛化的规则、需要人工确认的边界、可测试反例”写入对应设计文档，而不是只留下链接列表。

## 1. 调研目标

回答六个问题：

1. 数模论文从题目到提交，哪些工作可以稳定地由 skill 辅助？
2. 哪些质量问题会反复出现，且可以抽象为跨论文的检查规则？
3. 如何把术语、论证、阅读体验和自然表达放进同一条证据链，而不是最后做表面润色？
4. 在 AI 大量参与后，如何保留每道题的特征和团队的真实决策，避免论文趋同？
5. 各赛事对 AI 的允许范围、披露字段和提交位置有哪些差异？
6. 怎样在长会话和上下文受限时保留可追溯的 AI 使用记录？

## 2. 板块与出口条件

| 板块 | 核心问题 | 主要来源 | 出口条件 |
|---|---|---|---|
| 题意与建模 | 如何防止误读题意、几何结构、边界条件和目标函数 | 历史数模项目、竞赛论文、建模教材 | 有问题地图、歧义清单、人工确认门 |
| 数据与实验 | 如何防止口径漂移、数据泄漏、伪验证和图表误导 | 统计/机器学习规范、优秀论文、历史项目 | 有数据字典、实验注册、验证清单 |
| 术语与论证 | 哪些术语必须规范，哪些是生造和过度包装 | 期刊写作指南、术语学实践、历史修稿 | 有术语账本和反例词表 |
| 阅读体验 | 如何检查读者能否复原“问题—方法—证据—结论” | 期刊作者指南、审稿指南、真实论文 | 有分层读者检查与结构审查 |
| 反同质化 | 如何识别模板化建模、结构、术语、图表和贡献叙述 | 竞赛论文、历史项目、开源 academic skills | 有差异化账本、同质化诊断和反强行创新规则 |
| AI 模板化识别 | 识别哪些表达/结构值得人工重写，不能做作者归因 | 开源 humanizer/reviewer skill、写作研究 | 有证据化信号分类和不确定性说明 |
| 自然化修稿 | 如何去模板化而不改变内容、数字、语气和责任边界 | 开源学术 humanizer、中文学术写作规范 | 有前后对照、变更日志和防漂移测试 |
| 审稿与完整性 | 如何分离实质错误、表达问题、合规问题 | 开源 reviewer skill、COPE/期刊指南 | 有证据锚点、严重性、置信度和修复动作 |
| 赛事合规 | AI、页数、附录、支撑材料和身份信息限制如何适配 | 各赛事最新官方规则、本地格式 PDF | 有规则 profile、来源日期和冲突处理 |
| AI 使用披露 | 如何从本地日志和历史会话生成真实可核查的详情 PDF | 官方赛事规则、COMAP/出版伦理指南 | 有事件 schema、未知状态、人类签字/确认门 |
| 工程与开源 | 如何让 skill 可复用、可测试、可维护 | Codex skill 规范、GitHub 高质量 skill | 有目录规范、验证脚本、fixtures 和变更记录 |
