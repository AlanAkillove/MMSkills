# ADR 0002：AI 使用披露采用赛事规则适配器

- 状态：Accepted for design phase
- 日期：2026-08-31

## 背景

不同数学建模赛事可能对 AI 的允许范围、是否需要披露、披露字段、原始问答、提交位置和支撑材料有不同要求；规则还会随年份调整。CUMCM、本地格式规范和 COMAP 的公开政策不能直接互相替代。

## 决策

把规则独立建模为 `rules_profile`，至少包含赛事、年份、官方来源、发布日期、适用范围、允许/限制/禁止行为、披露字段、提交位置、文件限制和人工确认要求。AI 披露 skill 只根据已加载的 profile 生成最终文案；无法核验的规则进入 `unknown` 并阻断正式输出。

## 理由

- 防止把旧规则误用到新比赛；
- 允许同一事件记录渲染为不同赛事格式；
- 让来源和冲突可审计；
- 保留“实质风险”和“规则状态”两个独立维度。

## 后果

- 初期需要建立规则来源数据库；
- 每次赛事规则更新都可能触发适配器和 fixtures 更新；
- 在没有官方文本时只能生成内部草案，不能给出合规保证。
