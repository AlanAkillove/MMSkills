# ADR 0003：把反同质化设为全流程一级质量目标

- 状态：Accepted for design phase
- 日期：2026-08-31

## 背景

AI 辅助使数模论文更容易共享相似的题意拆解、模型清单、章节结构、贡献表述、图表套路和总结句式。仅在成稿后做“降 AI 味儿”不能恢复已经被抹平的题目特征和团队决策；而只做词汇多样化又可能产生生造术语、复杂化和事实漂移。

## 决策

将反同质化拆成两个阶段：

1. `modeling-distinctiveness-coach` 在题意、模型和实验阶段建立差异化账本，保留题目特征、真实观察、方案取舍、失败边界和人类决策；
2. `modeling-anti-homogenization-auditor` 在成稿后审查题目、建模、证据、术语、图表和表达层的模板化风险。

两者都不得输出原创度百分比、AI 率、抄袭结论或作者身份判断。差异化建议必须有题目依据、技术功能和验证证据；无法解释必要性的内容优先删除。

## 理由

- 论文差异的可靠来源是问题特征和团队判断，不是随机换词；
- 写前记录能减少后期补动机、补证据和反复改结构；
- 成稿审查可发现不同阶段累积的模板化和术语漂移；
- 与语言自然化分离后，可以防止“为了自然而改变实质”。

## 后果

- 需要新增差异化账本和对应 fixtures；
- 反同质化审查将比普通拼写检查更依赖人工判断和证据锚点；
- 不同赛事的保密/外部材料限制必须在比较论文或语料库前先检查。
