# ADR 0001：采用全流程编排并设置人类决策门

- 状态：Accepted for design phase
- 日期：2026-08-31

## 背景

历史项目显示，后期反复润色往往不是单纯句式问题，而是由题意误读、假设未登记、模型选择未解释、证据不足、术语膨胀、论文趋同和图表/正文脱节共同造成。如果只做“审稿 skill”和“去 AI 味儿 skill”，会把上游问题推迟到最昂贵的阶段。

## 决策

采用从题目接收、规则画像、问题分解、数据与模型、实验验证、论文写作、反同质化、审查、自然化、提交预检到 AI 披露的全流程架构；用共享状态文件连接 skills；在题意、假设、模型、数据、差异化设计、结论和最终披露处设置人类确认门。

## 理由

- 上游结构化状态能减少上下文丢失和重复返工；
- 人类确认门保留核心建模责任和竞赛主体责任；
- 分专项 skill 比一个超长 prompt 更容易验证、替换和扩展；
- 结果能同时服务完整建模、审稿、修稿和过程披露；
- 反同质化从题意和模型阶段开始，避免最后只做表面改写。

## 后果

- 流程比一次性生成更长，需要记录状态和确认；
- Agent 不能在用户未确认时自动跨越核心决策；
- 需要设计高效的批量确认界面和长文分块策略。
