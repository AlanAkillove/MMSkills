# 数模研究与论文质量模型

本模型描述结果应满足的质量维度。它评价研究与论文本身，不规定必须先跑哪个技能、必须生成哪份账本，也不把某一条实现路径写成普遍要求。

每个问题都应尽可能落到“证据位置—风险—修复动作—人工确认”，而不是只有主观评价。

## 1. 一级维度

| 维度 | 核心问题 | 典型失败表现 |
|---|---|---|
| 题意忠实 | 论文是否正确理解题面、对象、边界和任务 | 把结构关系看反；将示意图视觉印象当作事实；漏掉边界情形 |
| 模型合理 | 模型是否由对象、机理、约束、数据和任务决定 | 为显得高级使用复杂方法；模型与数据或题意不匹配；静默改题 |
| 证据充分 | 主张是否有直接证据，证据是否支撑主张强度 | 用一张图支撑多层结论；相关性写成因果；结论超出实验范围 |
| 计算可靠 | 数据口径、实现、数值核验和复现入口是否可复核 | 训练测试泄漏；只展示最好结果；代码与论文数字不一致 |
| 术语稳定 | 术语是否标准、必要、定义清楚且前后一致 | 给普通事实造新名词；同一概念多称；高承诺词没有证据 |
| 论文清晰 | 读者能否定位问题、方法、证据和结论 | 章节齐全但像清单拼接；图表与正文脱节；有效边界被元话语淹没 |
| 结果可追溯 | 数字、图表、引用和代码能否回到来源 | 附录代码不能运行；结果无法复算；文件列表不完整 |
| 规则合规 | 提交内容是否符合目标赛事与格式边界 | 电子版包含不应出现的页面；身份信息泄露；AI 披露字段缺失 |

以上维度可以叠加检查，不要求按固定顺序完成。选题比较、背景熟悉、基线实验或主张矩阵是可选工作方式，不是质量成立的前提。

## 1.1 与竞赛评阅重点的对齐

以 CUMCM 官方评阅材料为一个可配置的参考，技能可以把以下四个高层问题贯穿到审查中：

- 假设是否合理，并且没有悄然改变题意；
- 建模是否体现题目驱动的创造性，而不是强行换算法或造概念；
- 结果是否正确、可复核，且结论强度没有超出证据；
- 表述是否清晰，使评阅者能沿着问题、模型、证据和结论阅读。

这四项是检查方向，不是自动评分器。相似度筛查、词汇多样性指标和 AI 检测器只能提供待核实线索，不能单独证明抄袭、AI 生成、作者身份或论文质量。其他赛事应由规则配置覆盖或调整本节适用范围。

## 2. 高频反模式

### 2.1 高级感替代了信息

将普通描述包装成新概念，但没有带来新的变量、定理、指标或决策价值。处理方式：先问该术语是否在全文至少承担两次以上明确功能；若不能，用普通、标准且可读的表达替代。

### 2.2 结构完整但论证不连

论文有摘要、模型、算法、实验和结论，却像模块拼装。处理方式：检查每一节为哪条主张提供什么证据；缺证据时限缩主张，而不是补空章节。

### 2.3 语言很顺但事实漂移

润色时偷偷改变数值、条件、因果强度、引用范围、符号或作者立场。处理方式：修改前后对照、数字/公式/引用锁定、变更日志和人工抽查。

### 2.4 以 AI 检测器代替文本判断

检测器的误报、跨语言偏差和可操纵性使其不能作为作者归因或违规判定。处理方式：只报告可观察的模板化信号，并以证据和作者确认作最终判断。

### 2.5 用“反同质化”掩盖过度设计

为了与常见论文区分而强行增加复杂算法、新概念或不必要图表。处理方式：任何差异化设计都必须有题目依据、技术功能和验证结果；不能解释其必要性的内容优先删除。

### 2.6 防御性声明替代有效边界

论文需要报告适用范围、误差、不确定性、失败、局限和合规信息；问题在于同一免责句式反复出现，却没有新增条件、证据或范围。处理方式：逐句分类，保留有效边界；只删除没有独立信息的元话语。

## 3. 严重性分级

- `P0`：事实、数学、数据或规则错误，或会导致错误提交。
- `P1`：主要主张缺证据、模型不适配、验证不足或严重阅读障碍。
- `P2`：术语漂移、段落逻辑、图表说明、引用位置等重要但可局部修复的问题。
- `P3`：句式、标点、局部冗余和排版微调；不得为了修 P3 引入 P0/P1 漂移。

分级描述问题严重程度，不自动规定必须停在哪个技能。

## 4. 证据和置信度

每个审查结论标记：

- `direct`：可直接定位到题面、正文、公式、数据、代码、图表或规则条文；
- `inferred`：由多个直接证据推断，必须标明推断链；
- `unknown`：材料不足，不能确定；
- `external`：依赖外部规范/文献，必须给出处和适用范围。

任何“AI 味儿”“模板化”判断默认最多是 `inferred`，不应升级为作者来源结论。

## 5. 成功标准

高质量结果不等于问题数量多或句子更华丽，而应同时满足：

1. 核心事实、数学、数据和规则没有被改写错；
2. 读者能复原关键决策和证据链；
3. 术语数量受控，定义与使用一致；
4. 语言自然、直接、符合作者和学科语域；
5. 重要结论可验证，未知和局限被诚实保留；
6. 题目特征和团队真实判断没有被通用模板抹平；
7. 论文、代码、数据、图表、支撑材料和披露记录互相一致。
