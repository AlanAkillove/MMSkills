# 写作策略 profile

写作策略不是赛事官方规则。官方页数、摘要页、目录、匿名和文内引用义务写在 `references/rules/`。本目录只记录团队选择的成文策略。

当前已建立：

- [`cumcm-natural-cn.yaml`](cumcm-natural-cn.yaml)：中文 CUMCM 终稿。不写英文摘要；摘要按子问分段；禁止无序 `itemize`；禁止公式画框；禁止单独的「问题重述」章；孤立参考文献视为失败。短稿只在项目 preference 给出 `preferred_pages` 时触发覆盖审查，不得注水。
- [`project-overlay.example.yaml`](project-overlay.example.yaml)：项目级页数等个人策略，不进入公共默认。
