# Tests

测试分为三层：

1. **契约测试**：检查每个 skill 的触发边界、输入输出、人工确认点和必需字段；
2. **反例测试**：检查术语膨胀、结论过度、引用幻觉、数据泄漏、模板化语言和身份信息泄露；
3. **产物测试**：检查 Markdown/JSON/CSV/PDF 是否完整、可读取、可复现和版式可接受。

安装教程还应检查宿主能力探测、跨平台适配、权限安全、发现/激活/验证状态以及回滚说明，不能把文件复制成功等同于 Agent 已真正启用技能。

fixtures 必须脱敏。对于 AI 使用详情，至少测试：

- 有完整会话记录；
- 只有摘要、没有原始问答；
- 工具版本未知；
- 人类采纳情况未知；
- 同一事件在多个会话重复出现；
- 包含可能违规或需要人工升级的高风险事件。

TeX 模板还应通过结构契约检查，并在本地 TeX 环境可用时从干净目录执行 XeLaTeX、渲染 PDF，再抽查摘要页、公式/表格页和附录页；这类编译与视觉检查不由纯契约测试替代。
