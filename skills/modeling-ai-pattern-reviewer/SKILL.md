# 数学建模模板化痕迹审查

## 任务边界

本技能审查的是文本和论文结构中“看起来像通用模板、与题目脱节或表达过度均匀”的可观察信号，不是作者归因器、抄袭判定器或 AI 检测器。最终目标是恢复题目特征、真实团队判断和清晰阅读路径，而不是让检测分数下降。

明确边界：不判断作者身份、不判断文本是否由 AI 生成，也不把文本信号升级为来源结论。

必须区分：

- `observed_signal`：可以在具体句子、段落、章节、图表或跨产物中定位的现象；
- `interpretation`：该现象可能造成的阅读、论证或同质化风险，必须标置信心；
- `alternative_explanation`：合理的学科惯例、篇幅要求、题目限制或作者风格；
- `repair_option`：补充题目特征、删除空话、回退术语、重组证据或交给人确认的建议。

不能把“像 AI”“检测器判为 AI”写成来源事实，也不能凭少数常见连接词判定模板化。

## 何时触发

适用于：论文初稿/成稿的模板化诊断、反同质化审查、自然化修稿前的信号定位、不同版本之间的表达趋同检查，或审稿人要求说明论文是否过于套模板。

不适用于：直接重写论文、降低检测器分数、判断作者身份、判断抄袭、只改错别字，或在竞赛窗口内未经授权比较外部/其他队伍材料。需要修改时，把已确认的诊断交给自然化技能。

## 输入与读取顺序

1. 固定论文版本/hash、题面/问题地图、差异化账本、主张—证据矩阵、术语账本、图表注册和未读取材料。
2. 先从摘要、目录/章节结构、各节开头结尾、结论和图表说明建立信息架构，再看句式和词汇；不要把局部词频当作全篇结论。
3. 按 [signal-taxonomy.md](references/signal-taxonomy.md) 从结构、句法、词汇、论证和图表五个层面抽取信号；每条至少带两个原文位置或一个位置加对照证据。遇到重复的自我免责/元话语时，读取共享的[防御性声明处理协议](../../references/defensive-statement-protocol.md)，区分无信息的声明簇与必要的范围、局限和合规说明。
4. 按 [pattern-audit-protocol.md](references/pattern-audit-protocol.md) 检查替代解释、题目特异性和修复优先级；需要审计研究依据时再读取 [research-basis.md](references/research-basis.md)。
5. 若用户授权比较内部语料库，只能在规则 profile 允许、材料已脱敏且竞赛保密边界允许时使用；相似性只作线索，不作来源、抄袭或违规结论。

## 工作流程

### 1. 建立观察基线

标出论文自身的正常学科惯例：题目要求的固定章节、数学符号、标准摘要句式、必要的算法步骤和重复的变量名。没有基线，就不能把规范表达误报为模板化。

### 2. 检查五个层面

- **结构**：每个子问复制相同的“背景—模型—求解—结果—优点”套路，却没有题目特有的输入、约束、失败边界或证据角色；
- **句法/篇章**：固定开头、均匀三点式、连接词过密、长句叠加、过度对称、空洞因果、每段同样节奏，或连续堆叠没有新增信息的防御性声明；
- **词汇/术语**：抽象名词堆叠、宣传性形容词、无功能高承诺词、同义词轮换、英文缩写堆叠；
- **论证/证据**：贡献、创新、展望和结论没有题目特异性对应，或主张与证据矩阵没有锚点；
- **图表/交付**：图表模板重复、图表只装饰不回答问题、相同布局掩盖不同证据任务，或图注与正文套话化。

### 防御性声明簇

把“需要指出的是”“值得注意的是”“本文不意味着……”等表面标记只当作候选线索。只有当相邻声明重复同一免责功能、没有新增条件/证据/范围，并且增加读者注意力负担时，才记录为 `defensive_statement_cluster`。单独的有效局限、适用范围、不确定性、伦理/隐私或赛事要求声明不是模板化信号；删除建议必须交给自然化技能，并保留主张边界。

### 3. 逐条记录而不是贴总标签

每条信号写清原文位置、重复/对照位置、具体模式、为什么会增加阅读摩擦或抹平题目差异、合理替代解释、置信度（`high/medium/low`）和严重性（`P0–P3`）。同一底层问题的多个表象要合并，不能为了数量重复报错。

### 4. 回到题目和证据

检查该段是否包含题目特有对象、约束、观察、模型取舍、失败边界、验证设计或人类决策。若只是表达模板但证据链真实完整，可标为低风险；若题目特征/证据缺失，应转为结构或主张问题，而不只要求换词。

### 5. 提出最小修复路线

优先级依次为：补回题目特异性和证据 → 删除无信息模板 → 合并重复论证 → 回退生造术语 → 调整段落功能和句式 → 处理局部词语。不要通过故意口语化、打乱逻辑、随机同义替换或添加无关细节制造“人味”。

## 最低交付物

默认生成 `ai_pattern_report.md`，至少包括：

- 审查范围、版本、读者任务和未读取材料；
- 结构/句法/词汇/论证/图表五层的观察信号；
- 防御性声明候选的句子位置、功能分类、重复范围和 `retain/merge/remove/human_review` 建议；
- 每条信号的原文锚点、对照、影响、替代解释、置信度和严重性；
- 与题目特征、差异化账本、主张—证据矩阵的断链；
- 可保留的真实作者/题目差异；
- 最小修复选项及其是否需要回退到题意、假设、主张或术语技能；
- 人工确认队列和不应自动修改的内容。

## 阻断与严重性

- `P0`：模板化判断掩盖题意错读、关键证据缺失、身份/保密风险或将外部相似材料当成抄袭证据；
- `P1`：主要章节/结论与题目特征脱节、通用模型/贡献叙述替代真实决策、结构重复导致读者无法定位证据；
- `P2`：高频套话、三点式、术语包装、段落同构或图表说明重复，但不改变实质；
- `P3`：局部句式、标点或轻微重复。

任何 `P0/P1` 应先回退到实质问题或交人工确认，不能通过表面换词关闭。

## 硬性禁令

- 不说“这段一定由 AI 生成”“作者是 AI”“AI 率为多少”或“检测器证明了来源”；
- 不把单一词频、困惑度、相似度或检测器分数当成作者归因/抄袭/违规事实；
- 不在无授权、违反赛事保密规则或含身份信息的情况下抓取/比较其他论文；
- 不为了降低信号分数删掉真实失败、局限、适用范围、合规声明、标准术语、必要重复或题目要求的结构；
- 不把合理学科惯例自动判为模板化；必须呈现替代解释和证据边界；
- 不直接改写原文，不改变数字、公式、引用、主张、题目特征或作者决策；
- 不输出原创度百分比、同质化百分比或任何伪精确总分。

## 人工确认与交接

结尾必须给出 `status`（`draft`/`needs-human-confirmation`/`human-confirmed`/`blocked`）、审查范围、已确认信号、待确认信号、未评估材料、允许的下一步和禁止的下一步。`human-confirmed` 必须记录确认人、日期、确认范围、决定和 `decision_id`。自然化或结构改写前，必须把修复选项和可能改变的实质内容交给人确认。
