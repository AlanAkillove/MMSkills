# 模板化审查工作流

## 先建立基线

记录论文必须遵守的结构、题目固定术语、标准公式表达、必要的重复变量和统一图表规范。审查对象是“无功能的均匀化/通用化”，不是形式规范本身。

## 从信号到问题

每条观察按以下链条写：

```text
原文锚点
→ 可重复的具体模式
→ 与题目特征/证据的对照
→ 对读者或论证的影响
→ 合理替代解释
→ 最小修复选项
→ 人工是否需要确认
```

如果不能完成“原文锚点”和“对照”，只能写成未确认线索，不能列为主要问题。

## 与内部语料库比较

只有在用户明确授权、规则 profile 允许、材料已脱敏且不违反竞赛保密/知识产权边界时，才可比较已授权语料。报告只能说“与语料中的某些表达相似/存在重复线索”，不说抄袭、AI 生成或作者来源；不要把跨题目共用的标准术语和格式段落纳入相似性结论。

## 修复优先级

1. 题意、证据、模型和作者决策断链：回退实质阶段；
2. 通用模板替代题目特征：补回真实观察/取舍/边界；
3. 空话或重复论证：删除/合并；
4. 高承诺术语：交术语和主张技能；
5. 句式问题：只对已登记且命中的 `signal_id` 做最小必要调整；长句和节奏交给阅读体验审计。

不要为了修复低层信号破坏上层证据、标准术语或读者导航。

## 多版本比较

比较版本时固定同一章节、同一主张和同一证据范围，区分：

- 作者主动统一术语/格式；
- 修稿后新增模板化句式；
- 实质内容改变造成的结构变化；
- 上下文截断造成的假性重复。

只报告可见变化，不能从文本差异反推谁写了哪一部分。
