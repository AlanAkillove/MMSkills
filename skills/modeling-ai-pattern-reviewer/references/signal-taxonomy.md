# 模板化信号分类

本表用于提出可核验观察，不是“AI 特征词典”。同一信号必须结合题目、证据和作者惯例判断。

## 五层信号

| 层面 | 可观察信号 | 需要的对照 |
|---|---|---|
| 结构 | 每个子问复制相同章节套路；背景/创新/展望可替换到别题；模型清单与题目特征无关 | 子问映射、题目特有事实、差异化账本 |
| 句法/篇章 | 固定模板开头、连接词堆叠、均匀三点式、长句叠加、过度对称、空洞因果、每段同节奏；没有新增信息的防御性声明簇 | 同一论文其他段落、作者保留的实验/失败段、读者任务、防御性声明协议 |
| 词汇/术语 | 抽象名词堆叠、宣传性形容词、无功能高承诺词、同义词轮换、英文缩写堆叠 | 术语账本、定义/证据、普通直接表达 |
| 论证/证据 | 贡献/创新/结论没有 claim/evidence 锚点；主张强度相同而证据责任不同；局限只用模板句 | 主张—证据矩阵、实验登记、假设账本 |
| 图表/交付 | 每图同样配色和叙述；图表装饰性强；图注只是“如图所示”；不同证据任务使用同一模板 | 图表注册、源代码、图表回答的问题 |

## 不足以单独构成信号的现象

- 使用“首先/其次/最后”、标准章节、数学被动句或常见连接词；
- 语法正确、句子正式、术语重复、图表风格统一；
- 某个检测器分数、词汇多样性指标或跨论文相似度结果；
- 由题目要求、篇幅限制、学科惯例或团队统一模板造成的重复。

这些只能与具体信息缺失、题目脱节或证据责任不匹配结合后提出低/中置信度观察。

## 防御性声明簇的专门判据

`defensive_statement_cluster` 是句法/篇章或论证/证据层的子类型，不是作者来源判断。候选句常包含元话语、自我免责或预先否认，但只有同时满足以下条件才提高置信度：

1. 在相邻句、同一小节或多个结论位置重复相同功能；
2. 删除或合并后不会丢失新的对象、条件、证据、范围、局限或合规要求；
3. 声明打断了结果—证据—边界的顺序，造成可定位的阅读负担。

若声明承担 `scope_boundary`、`uncertainty`、`limitation` 或 `ethics_compliance` 功能，应记录为需要保留/合并的保护内容，而不是删除目标。具体动作按共享的[防御性声明处理协议](../../../references/defensive-statement-protocol.md)执行。

## 记录格式

```yaml
signal_id: S-001
layer: structure | syntax | lexical | argument | figure
signal_family: defensive_statement_cluster | null
locations: []
observed_pattern: null
contrast_or_anchor: []
reader_or_argument_impact: null
alternative_explanations: []
confidence: high | medium | low
severity: P0 | P1 | P2 | P3
repair_options: []
requires_human_decision: true
```
