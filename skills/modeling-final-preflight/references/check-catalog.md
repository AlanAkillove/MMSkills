# 最终预检检查目录

具体字段由目标 `rules_profile` 决定，以下是跨项目的检查层。

## 身份与范围

- 目标赛事/年份/组别/赛区与 profile 一致；
- 论文、支撑、代码、数据、AI trace 和规则输入版本/hash 已固定；
- 论文、附录、支撑和元数据没有不允许的姓名、学校、赛区、报名号、路径或隐私；
- 所有外部/内部材料的授权范围已记录。

## 论文结构与格式

- 电子版首页、承诺/编号页排除、摘要/正文/附录和页码符合 profile；
- 正文页数、文件格式/大小、附录内容、声明位置和参考文献顺序符合规则；
- PDF/Word 文本层和渲染视觉检查状态明确；
- 目录、公式、图表、引用、标签和页码可定位。

## 内容与证据

- 题面子问题和特殊约束覆盖；假设和关键模型已人工确认；
- 主张—证据矩阵无未关闭 P0/P1，结论范围/条件/局限一致；
- 术语、变量、单位、数字和图表交叉引用一致；
- 实验、数据、代码和支撑材料状态明确，未将 unknown 当验证。

## AI 披露

- 按 profile 检查是否需要声明、声明原文/位置、详情文件和字段；
- 工具/模型版本、用途/阶段、提示/过程、采纳/修改/核验和未知字段有来源；
- 不从论文成品反推“未使用”，不把 Agent 提议写成团队采用；
- 人工逐项确认且隐私/未公开赛题已阻断。
