# 论证映射与篇幅分配

## 主线图

```text
题目子问题/特殊锚点
  -> 假设与变量/约束
  -> 模型/算法取舍
  -> 数据/实验/图表证据
  -> 有范围的主张
  -> 结论/局限/决策建议
```

每条箭头都要有 ID 或原文位置；断点写 `missing/unknown/conflict`。不要用“创新点”作为没有证据的中间节点。

## 篇幅预算

按主张承重和读者任务分配篇幅：关键模型/证据/结果优先；空泛背景、重复结论、算法百科和装饰图表压缩。若有赛事页数要求，先从规则 profile 读取；没有规则不猜上限。

## 摘要与结论回归

- 摘要至少能定位对象、任务、方法/决策、关键结果、条件/范围和必要局限；
- 结论逐条回指主张和 evidence ID，不添加正文没有的“创新/普适/政策意义”；
- 如果证据尚未冻结，摘要/结论只生成草案并标人工确认，不把占位词写成事实。

## 结构反模板检查

检查每节是否真的需要背景、方法、结果和展望；若所有小节都使用相同顺序但题目子问题不同，按证据链重排。固定章节本身不构成问题，问题在于它是否挤掉题目特异信息或让主张无法定位。
