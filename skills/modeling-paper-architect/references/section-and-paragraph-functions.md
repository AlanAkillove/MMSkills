# 章节与段落功能库

## 可选功能

| 功能 | 应回答的问题 | 常见越界 |
|---|---|---|
| 题目/问题分析 | 本题对象、任务、条件和子问题是什么？ | 复述宏大背景却不落到任务 |
| 假设/定义 | 哪些条件、变量和单位使模型可用？ | 把团队假设写成题面事实 |
| 模型建立 | 如何从对象/约束得到目标、方程和决策？ | 只列算法名，跳过映射 |
| 求解/算法 | 如何求解、参数和停止条件是什么？ | 把运行成功写成正确/最优 |
| 结果/验证 | 在什么数据/场景/基线下观察到什么？ | 只报最好结果或无范围数字 |
| 讨论/局限 | 结果在哪些条件下成立，哪里失败？ | 删除限制以制造完整故事 |
| 结论/建议 | 对各子问题给出什么有边界的回答？ | 引入未验证机制和普适意义 |

## 段落最小单元

```text
对象/主语 -> 动作/模型操作 -> 条件/范围 -> 结果/证据 -> 解释或下一步
```

不是每段都要机械包含全部五项，但其功能应可说明；如果段落只有“本文具有重要意义”等评价而没有对象/证据，应删减或回到对应上游材料。

## 写作交接

把每个段落的输入/输出 ID 和人工状态写入契约。Agent 可根据已确认字段起草表达，但不能补缺失证据、添加作者经历或替换术语。
