# 视觉与导航检查

## 文本层导航

- 标题/目录/小节是否能提示问题、方法、结果和局限；
- 每个题面子任务是否能沿小节、图表和结论找到回答；
- 首次出现的符号、缩写、算法和数据集是否有定义或指向；
- 图表、公式、附录、代码和引用的交叉引用是否存在、指向正确且在需要处解释；
- 段落是否有当前功能，是否出现“结果先于定义”“结论没有证据入口”“同一对象跨节换名”。

## 视觉层（有渲染件才执行）

记录 `render_tool`、版本、页码和对象锚点，检查：

- 标题孤行/悬挂、段落被不合理拆开、图表与图注/正文分离；
- 公式、变量下标、单位、表头、图例、颜色和字体在页面尺寸下可读；
- 表格溢出、裁切、重叠、空白异常、页眉页脚遮挡和跨页标识；
- 图表编号与正文/目录/附录一致，页面顺序不让读者错过条件和局限；
- PDF 的文本层可选取、公式/中文未乱码、链接/书签（若有）可用。

没有 PDF/图片/渲染件时，输出 `unassessed`，不要根据 Markdown 源码推断页面效果。发现文字内容问题时不要用排版调整掩盖它。

## 视觉问题与实质问题分流

- 图例模糊但数据和解释存在：视觉 P2，转交排版/图表审计；
- 图表缺单位或与正文数字不一致：可能是 P1 证据问题，转交图表/主张审计；
- 公式被裁切导致无法确认符号：P0/P1 视材料情况阻断，并记录页码和渲染件版本；
- 页面空白或断行仅影响观感：P3，不借此改变章节结构或添加内容。
