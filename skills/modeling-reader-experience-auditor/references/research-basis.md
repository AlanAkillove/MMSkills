# 设计依据与迁移边界

1. CUMCM 公开评奖原则把表述清晰与假设合理、结果正确、建模创造性并列；本 skill 将“清晰”具体化为读者任务、证据入口、技术复原和必要解释，而不是把篇幅或华丽程度当成质量。
2. [Nature Portfolio 写作指南](https://www.nature.com/nature-portfolio/for-authors/write)强调面向读者清楚呈现主要发现、解释必要术语和避免不必要行话。本 skill 只迁移读者路径和信息传递原则，不照搬 Nature 期刊格式、英文偏好或篇幅标准。
3. 历史项目中常见“章节齐全但像清单拼接”、术语/图表/代码入口断裂、插入内容导致回读负担；本 skill 用三条路径和渲染件检查将其独立化。
4. 与本项目的[审稿角色](../../modeling-paper-reviewer/SKILL.md)、[术语审查](../../modeling-terminology-auditor/SKILL.md)、[主张—证据审查](../../modeling-claim-evidence-audit/SKILL.md) 和[自然化修稿](../../modeling-paper-naturalizer/SKILL.md)衔接：本 skill 报告阅读摩擦和转交目标，不静默修正实质。

阅读体验是可观察的信息路径，不等于“更口语”“更少术语”或“更像人”。未提供渲染件时不做视觉通过判断，未提供读者目标时记录默认路径和假设。
