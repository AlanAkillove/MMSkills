# 设计依据与迁移边界

1. CUMCM 公开评奖原则要求假设合理、建模有创造性、结果正确、表述清晰；本 skill 把“创造性”落实为题目特征驱动的模型取舍和可检验证据，而不是模型复杂度或名称。
2. 本项目[差异化写前教练](../../modeling-distinctiveness-coach/SKILL.md)、[数据审计](../../modeling-data-audit/SKILL.md)、[假设账本](../../modeling-assumption-ledger/SKILL.md)和[历史问题归纳](../../../docs/research/historical-project-findings.md)共同指出“模型清单、静默假设、复杂化和无失败记录”是高频返工源；本 skill 将其前置到 registry 和人工决策。
3. [Yuan1z0825/nature-skills](https://github.com/Yuan1z0825/nature-skills)与公开 academic writing/review skills 的 evidence-first、候选比较和人类确认提供工程启发；不照搬期刊模型偏好或“先进”标准。
4. 结果、敏感性、稳健性和实验执行交给[实验验证 skill](../../modeling-experiment-validator/SKILL.md)；本 skill 不伪造实验结果。
5. 本项目的[质量模型](../../../docs/quality-model.md)把人类可决策性作为独立质量维度；因此本 skill 增加分层解释、分项评估和理解确认，而不是把复杂模型压缩成一个分数。

模型架构是决策记录，不是自动选模器。没有题意、数据和团队确认时只能保留候选和问题。
