# 设计依据与迁移边界

1. 本项目对 CUMCM 公开评奖原则和 2025 评阅工作规范的整理显示，建模创造性必须与题目适配、结果正确和表述清晰共同衡量；评阅规范还要求关注突出创新点并记录相似度/疑似抄袭线索。本 skill 将“创新”还原为题目特征驱动的决策、验证和证据，不将文本差异或模型复杂度当作创新证明。
2. 本项目[反同质化设计草案](../../../docs/anti-homogenization-design.md)和[历史问题归纳](../../../docs/research/historical-project-findings.md)记录了数模中最常见的趋同：同一套模型清单、固定三点式、换名词包装普通操作、删除失败过程和 AI 候选未经团队取舍。它们被转化为 `anchor → decision → validation → finding` 的账本，而不是固定禁用词表。
3. [Yuan1z0825/nature-skills](https://github.com/Yuan1z0825/nature-skills) 的模块化、按需读取和主张—证据契约提供工程启发；本 skill 不照搬 Nature 期刊风格、创新标准或英文论文结构。
4. 与本项目的[问题摄取](../../modeling-problem-intake/SKILL.md)、[假设账本](../../modeling-assumption-ledger/SKILL.md)、[术语审查](../../modeling-terminology-auditor/SKILL.md)、[主张—证据审查](../../modeling-claim-evidence-audit/SKILL.md) 和[审稿角色](../../modeling-paper-reviewer/SKILL.md)衔接；候选方向必须在模型/实验/人类决策 skill 中进一步确认。

本 skill 不能证明原创性，不能比较未授权论文，不能预言奖项，也不能让 Agent 代替团队创造差异。它只帮助保存真实、可解释、可复核的题目特异性。
