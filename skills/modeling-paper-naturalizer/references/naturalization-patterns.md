# 中文数模表达自然化模式

这些是“可选动作”，先判断当前句子的真实逻辑，再选择最小动作；不是固定替换表。

## 高频问题与安全动作

| 问题 | 安全动作 | 禁止的过度修复 |
|---|---|---|
| 空泛背景/意义 | 删除或换成题目对象、数据、约束和任务 | 添加社会价值、宏大背景或未给出的应用 |
| 段末重复总结 | 删除重复；若有必要改为具体边界/下一步 | 用“奠定基础/提供支撑”套话收尾 |
| 无主句/被动堆叠 | 补出已有材料中的本文、模型、样本、实验等主体 | 虚构作者经历或责任主体 |
| “通过 A 实现 B 从而 C”堆叠 | 按实际先后拆分动作、结果、条件和证据 | 擅自添加因果机制 |
| 机械并列框架 / 跨段同构 | 保留真实并列与分问事实；只拆没有论证功能、或跨子问重复的外壳 | 因“首先/其次/三”本身打乱顺序或强行口语化 |
| 抽象名词连续堆叠 | 换成对象—动作—结果，保留必要术语 | 同义词拼贴或生造新术语 |
| 连接词过密 | 删除无功能连接词，保留真实因果/转折/时间关系 | 用更多高级连接词遮住逻辑缺口 |
| 高承诺词 | 回退标准术语或限定范围 | 把观察改成定律/机制/鲁棒/最优 |
| 摘要/结论模板 | 回到问题、方法、关键结果、条件和局限 | 编造“创新点”或普适意义 |
| 防御性声明/自我免责 | 区分有效边界与无信息元话语；保留前者并把重复说明合并到结果/讨论，后者才删除 | 删除样本范围、误差、局限、伦理/隐私或规则要求；用同义词继续堆叠免责句 |

## 按章节的保守策略

- 摘要：保留对象、任务、方法、数据/场景、关键结果和局限；压缩泛泛背景；
- 问题分析/假设：保持题面术语、假设边界和不确定项；不为顺畅删掉条件；
- 模型与算法：以可复现为先，保留变量、步骤、公式、参数和代码入口；
- 结果：保留数字、方向、误差、不确定性、基线和图表定位；
- 讨论/结论：把“说明/表明”限定到证据范围，保留失败、局限和外推边界；
- 附录与图注：不把支撑材料、单位、变量或图表解释改成宣传语。

## 防御性声明的自然化

对“需要指出的是”“值得注意的是”“本文不意味着”“不能据此”等句式，只检查它们是否重复、是否阻断主线、是否承担真实边界。推荐把有信息的声明改为直接的“结果—条件—范围”表达，例如将有效局限紧接对应结果说明；不能把有效限定当作赘述删除。具体分类和记录字段见共享的[防御性声明处理协议](../../../references/defensive-statement-protocol.md)。

## “自然”判据

修改后至少应更容易回答：谁/什么对象做了什么？在什么条件下？证据在哪里？结果覆盖到哪里？如果只是换词、句子更长或更华丽，而这些问题没有变清楚，应撤回修改。
