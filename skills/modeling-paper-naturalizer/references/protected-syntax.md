# 公式、LaTeX、Markdown 与交叉引用保护

## 默认不可改动 token

- 数字、单位、百分号、范围、比较符号、变量/参数名和下标；
- `$...$`、`\(...\)`、`\[...\]`、数学环境及其内部命令；
- `\cite{...}`、`\ref{...}`、`\label{...}`、`\begin{...}`、`\end{...}`、BibTeX key；
- Markdown 链接、表格分隔、代码块、HTML/LaTeX 标签、图表/章节编号；
- 文件名、算法名、数据集名、专名和已有术语。

## 处理步骤

1. 复制原始文件并建立 token 清单/哈希；
2. 只在人类可读文本区域修改；
3. 对比 token 集合、顺序和引用/标签配对；
4. 渲染或至少进行语法/结构检查；
5. 对可能改变语义的保护 token 报告人工确认。

如果文件格式不明、命令嵌套复杂或无法区分正文与代码，先诊断并请求更安全的可编辑源，不要直接全篇替换。
