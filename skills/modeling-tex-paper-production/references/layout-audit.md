# TeX 版式审计清单

这是源稿和 PDF 页面层面的检查，不替代数学、数据、引用、术语和赛事合规审计。每项登记 `pass`、`fail`、`unknown` 或 `unassessed`，并附文件/页码/行号锚点。

## P0/P1 检查

| 类别 | 检查问题 |
|---|---|
| 编译 | XeLaTeX/指定引擎能从干净目录重建 PDF；无 error、未定义引用、未定义标签和 missing file |
| 页面 | 纸张、方向、边距、首页和页码起点符合 profile；没有意外空白页 |
| 内容边界 | 摘要/summary、正文、参考文献、附录、AI 声明和支撑材料清单处于规则允许的位置 |
| 匿名 | PDF 文本、书签、元数据、图片/代码路径中没有不应出现的姓名、学校、地区、队号或本机路径 |
| 页数 | 按 profile 的定义分别统计正文、solution、附录和 AI report；不能只报告 PDF 总页数 |
| 证据 | 图表、公式、引用和附录入口都能回到源文件、数据/实验/文献或登记的人工决定 |
| 可读性 | 真实嵌入尺寸下文字、公式、图例、单位、表头、代码和页码可辨认；没有遮挡/裁切/溢出 |

## P2/P3 检查

- 标题层级是否只保留承担读者任务的层级；
- 段落是否因强制分页、过度 `\newpage` 或浮动体漂移而被切碎；
- 图表是否靠近首次解释处，图注是否比图中重复文字更有信息；
- 表格是否可以在一眼内比较，是否需要 `longtable` 或转入附录；
- 公式编号是否稳定、是否只给需要回引的公式编号；
- 中文标点、半角/全角、负号、乘号、单位、空格和英文缩写是否统一；
- 目录/书签文本是否自然，不含 TeX 命令和过长标题；
- 视觉风格是否服务于题目证据，而非套用固定色块、阴影或“高级感”装饰。

## 必须回退的信号

看到以下情况时不要继续微调间距：

1. 图表和正文数字不一致，或图注改变了主张；
2. 公式中的变量、单位、符号与术语账本冲突；
3. 通过删掉不利结果、隐藏页码、缩小字号或透明文字解决页数/匿名问题；
4. AI 声明、参考文献或支撑材料详情无法从授权历史恢复；
5. 使用第三方 class、字体或 Logo 的许可证和版本不明；
6. 页面显示成功但 PDF 文本不可复制、公式/中文被替换为方框或阅读顺序损坏。

## 输出格式

推荐每条记录：

```text
finding_id | severity | status | source_anchor | page_or_line | observed_problem | impact | smallest_fix | owner | recheck
```

版式审计报告最后必须列出：未评估范围、需人确认的开关、构建命令、输入/输出 hash、页面抽查清单和下游审计 skill。
