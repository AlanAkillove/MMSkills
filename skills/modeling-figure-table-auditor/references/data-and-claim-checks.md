# 图表数据与主张核对

## 溯源链

```text
raw/derived data
  -> transform/filter/aggregation
  -> experiment output
  -> plotting code/config
  -> figure/table file
  -> caption and paper text
  -> claim/evidence matrix
```

每个箭头记录文件/代码/命令/版本或 `unknown`。图像只有像素、源表或代码缺失时，不反推精确数值。

## 数值与单位

- 行数、分组数、均值/总量、百分比/百分点、误差/区间和有效数字与源输出一致；
- 轴/表头/图例单位明确，换算公式和舍入可复核；
- 比较对象、基线、时间/实体范围和过滤规则与实验注册一致；
- 图表数字与正文、摘要、结论和代码日志一致；
- 颜色/排序/轴截断不制造论文没有证明的视觉结论。

## 主张边界

把每条图表观察拆成原子主张，核对证据支持范围：

| 图表语言 | 可支持的最小含义 | 需要额外证据的强含义 |
|---|---|---|
| 曲线在当前范围上升 | 指定数据/参数范围的变化 | 普遍单调、机制、因果 |
| B 的指标低于 A | 指定切分/指标下的比较 | 全局最优、所有场景更好 |
| 两变量同向 | 当前样本的关联 | 因果、理论规律 |
| 扰动下变化小 | 所测场景中的变化 | 对所有扰动稳健 |

任何强含义转交主张—证据审查。
