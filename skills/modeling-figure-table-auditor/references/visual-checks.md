# 图表视觉检查

## 有渲染件才判断页面

记录渲染工具/版本、页面和对象锚点。检查：

- 标题/图注/正文与图表是否邻近且不分离；
- 图例、坐标、表头、单位、下标、颜色、线型和有效数字是否可读；
- 字体、线宽、颜色在打印/灰度或低分辨率下是否可区分；
- 图表是否裁切、重叠、溢出、过度压缩或与页眉页脚碰撞；
- 空白、比例和排序是否妨碍读者理解，但不以填满页面为目标；
- 交叉引用、编号、书签/链接（若有）是否正确；
- 图表、数据和代码中是否出现身份、学校、赛区或隐私信息。

没有渲染件时写 `unassessed`。源码的尺寸不能证明 PDF 页面效果。

本文件中的可读性核对仍属于审计侧的可观察项。进正文的承重图另需独立 Subagent 做 fresh-reader visual review：不问作者为何喜欢这张图，只问第一次看见的人能否完成 `reader_task`。

## 可读性与证据分流

- 图例太小但数据链正确：视觉 P2，转交排版；
- 缺单位/比较对象或数字不一致：数据/主张 P1，不能只换字体；
- 图表裁切导致关键数值/约束无法确认：视影响为 P0/P1；
- 配色偏好不影响区分：P3，不能借此重做结论图。
