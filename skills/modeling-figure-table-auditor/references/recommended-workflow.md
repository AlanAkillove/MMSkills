# 图表审计的推荐工作流

本文件是按需读取的详细协议，不是每轮必须执行的 SOP。用户只要核一个面板、图注或单位时，聚焦对应风险。

## 需要完整审计时的顺序

1. 先写图表回答的问题和对应主张。
2. 从源数据到绘图代码、图注和正文回查筛选、单位和版本。
3. 检查标题、坐标、图例和颜色是否暗示未证明的顺序或因果。
4. 正文应指出读者看什么，而不是只写“如图所示”。
5. 在渲染件中检查裁切、重叠、灰度和交叉引用。

## 需要落盘时的最低交付

`figure_table_registry.md`、`figure_table_audit.md`、`figure_table_findings.jsonl`。JSONL 遵守共享 `finding.schema.json`，并保留 `claim_ids` 与输出 hash。
