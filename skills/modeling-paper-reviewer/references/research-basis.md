# 设计依据与迁移边界

1. [全国大学生数学建模竞赛赛区评阅工作规范（2025 年修订稿）](https://www.mcm.edu.cn/html_cn/node/011a3fefdb4951a8cb595400f44ec3df.html) 要求评阅前统一评阅要点、匿名和回避、每篇至少三位评委独立评阅，并对突出创新点和相似度/疑似抄袭线索单独处理。本 skill 只迁移“统一标准、独立发现、证据记录、复议/人工确认”的质量原则，不伪装真实评委，也不照搬赛区比例或相似度阈值。
2. CUMCM 的公开评奖原则将假设合理性、建模创造性、结果正确性和表述清晰作为高层方向。本 skill 将其拆成题意、模型、数据实验、主张证据和阅读表达透镜；高层方向不等于分数公式。
3. [COPE Peer Review Guidelines](https://members.publicationethics.org/sites/default/files/cope-ethical-guidelines-peer-reviewers-v2_0.pdf) 强调保密、客观、具体、基于证据并区分意见与事实。本 skill 加入竞赛保密边界、alternative explanation、confidence 和 acceptance test。
4. [ECC scientific-thinking-scholar-evaluation](https://github.com/affaan-m/ECC/blob/main/skills/scientific-thinking-scholar-evaluation/SKILL.md)、[paper-review-skill](https://github.com/chunhualiao/paper-review-skill/blob/main/SKILL.md) 和 [open-science-skills journal-review](https://github.com/scdenney/open-science-skills/blob/main/codex/journal-review/SKILL.md) 提供了范围 manifest、证据锚点、分层审查、独立冻结后综合等工程启发；本项目按数模题面忠实度、模型适配、代码/数据复核和赛事规则重建。
5. 与本项目的[主张—证据审查](../../modeling-claim-evidence-audit/SKILL.md)、[术语审查](../../modeling-terminology-auditor/SKILL.md)、[AI 模板化痕迹审查](../../modeling-ai-pattern-reviewer/SKILL.md) 和[问题摄取](../../modeling-problem-intake/SKILL.md)衔接；本 skill 发现缺口后转交相应专项 skill，不把所有问题塞进审稿意见。

本 skill 不能证明论文原创、不能替代真实赛区评阅，也不能从文本风格反推 AI 来源。任何未读取的代码、数据、题面图示或规则都必须在报告中显式列出。
