# 术语跨产物一致性检查

术语审查不仅针对论文正文。以 `concept_id` 为中心，把同一概念在各产物中的名称和含义对齐。

## 检查矩阵

| 产物 | 检查项 |
|---|---|
| 题面/问题地图 | 对象、子问题、关系和题目原词是否被改成别的概念 |
| 假设账本 | 假设对象、范围和边界是否与论文同名同义 |
| 数据字典 | 列名、指标、单位、缺失/异常定义是否与论文一致 |
| 模型/公式 | 符号、下标、域、变量/参数角色和量纲是否稳定 |
| 代码 | 变量/函数/文件名是否能映射到论文术语；旧名是否有记录 |
| 图表 | 标题、图例、坐标轴、颜色和表头是否使用规范名和单位 |
| 主张矩阵 | 主张中的对象和指标是否指向同一 `concept_id` |
| 附录/支撑材料 | 代码说明、文件名和运行输出是否沿用相同概念 |

## 修复顺序

1. 先确定 `concept_id` 和规范名；
2. 再修正首次定义和术语账本；
3. 然后按产物逐处改名，并复核范围、单位、否定和因果强度；
4. 最后做数字、公式、图例、引用和代码入口的回归。

不得以全局替换代替逐处复核：一个词在不同上下文中可能确实指不同层级或统计量。
