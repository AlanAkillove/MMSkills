# 冲突、有效期与更新

## 冲突分类

- `scope_conflict`：同一文件对不同组别、赛区、阶段分别规定；先拆适用范围，不视为矛盾；
- `version_conflict`：新旧届次/修订稿不同；记录替代关系和生效日期；
- `authority_conflict`：官方组委会与赛区/学校附加规定不一致；保留两条并交目标范围人工确认；
- `content_conflict`：同一适用范围的官方来源直接冲突；状态保持 `conflict`，不选最严格/最宽松版本；
- `extraction_conflict`：网页、PDF 抽取和视觉页图不一致；回到原文或标 `unknown`。

## 新鲜度检查

每次使用 profile 前检查：

1. 当前日期是否晚于 `next_review` 或来源有效期；
2. 官方站点是否发布新修订、报名须知、赛区通知或提交系统变更；
3. 用户给的本地 PDF 是否与官方链接/内容 hash 一致；
4. AI/保密规则是否在本届新增，不能只复用格式规范；
5. 下游 profile 是否引用旧字段或已失效文件名。

过期时可以输出旧版历史对照，但状态标为 `stale`，不做正式合规结论。

## 人工升级问题

用具体问题升级：

- “该条规则适用于本科组还是所有组别？”
- “赛区附加通知是否覆盖全国组委会页面的这一字段？”
- “规则说‘原则上’时，提交系统的实际硬校验是什么？”
- “AI 参与代码/模型建议是否需要逐项披露，官方原文是否有例外？”

不要用“应该没问题”关闭冲突。
