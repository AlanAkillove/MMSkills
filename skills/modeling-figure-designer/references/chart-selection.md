# 选图与证据编码

选图顺序是“变量关系 → 读者任务 → 证据角色 → 图型 → 视觉编码”。不要从喜欢的样式、默认模板或某个期刊截图反推图型。

## 数据关系到图型

| 数据关系/任务 | 首选方案 | 必须说明 | 常见误读与修复 |
|---|---|---|---|
| 少量类别的数值比较 | 点图、区间点图；零点有意义时可用条形图 | 比较对象、基线、排序规则、误差含义 | 非零截轴夸大差异；改用零基线或直接标注差值 |
| 有序时间/迭代过程 | 折线、阶梯线、小倍图 | 时间/迭代顺序、采样间隔、区间或重复 | 把无序类别连成线；改为点图/排序条形图 |
| 分布与异常 | 原始点 + 箱线/区间、小提琴（样本足够时） | 样本量、统计量、异常点规则 | 只有摘要箱线图掩盖小样本；叠加原始点或使用表格 |
| 两变量关系 | 散点、分面散点、残差图 | 观察关系与拟合模型分开、分组和参考线 | 把相关写成因果；只在有模型/假设时画拟合线 |
| 多指标/多方案结果 | 小倍图、分组点图、平行坐标（维度少时） | 指标方向、量纲、归一化和权重 | 不同量纲直接叠图；拆面板或保留结果表 |
| 参数扫描/空间矩阵 | 热图、等高线、面图（3D 非默认） | 色带方向、缺失区、等值线和取值范围 | 彩虹色带造成假梯度；用顺序/发散色带并标单位 |
| 约束与可行域 | 可行域填充、边界线、等高线、候选点 | 约束、边界、目标函数和不可行区域 | 只标最优点不展示边界；先展示可行域再标候选 |
| 敏感性与稳健性 | 基线对比折线、区间带、龙卷风图、参数热图 | 基线、变化范围、扰动方式和评价指标 | 只展示单一最好点；补全范围并写适用条件 |
| 预测/拟合与观测 | 点线 + 预测/置信区间、残差图 | 区间定义、训练/验证范围和单位 | 混淆置信区间与预测区间；图注明确对象 |
| 网络/几何/空间结构 | 可编辑矢量图、分层网络、几何构造图 | 节点/边/坐标/方向/尺度和题面映射 | 只靠颜色表示关系；加线型、箭头、标签或形状 |
| 模型/算法步骤 | 分层流程图、输入—处理—输出图 | 每个节点功能、决策点、循环和产物 | 只堆模块名称；写出关键输入、判断和输出 |
| 精确结果查阅 | 表格，必要时配一张概览图 | 小数位、单位、缺失值、排序和来源 | 复杂图替代精确数字；让图和表各承担不同任务 |

## 选图记录模板

```text
读者问题：
变量关系：
证据角色：
候选图型：
最终图型与理由：
未采用的相邻图型及理由：
必须显示的基线/边界/不确定性：
不应由图形暗示的结论：
```

## 反模式检查

- `3D` 透视、阴影和渐变只有在第三维本身是读者任务时才考虑；否则会增加遮挡和读数误差；
- 双纵轴会使两个尺度产生视觉上的虚假对齐，优先分面或标准化并明确转换；
- 饼图/环图只适合少量互斥构成且总和有清楚意义的场景，比较细小差异时改用点图/条形图；
- 雷达图和仪表盘常把不同量纲包装成面积/角度比较，除非权重和量纲已被确认，否则改用小倍图或表格；
- 彩虹、`jet`、随意红绿对比和只靠颜色的多类别编码不作为默认方案；
- 误差线、阴影区间、拟合线、星号和“最优”标记必须有数据/统计/优化定义；没有定义就删除或标 `unknown`；
- 面板、标签和注释不是越多越好。每增加一个视觉元素都要回答“它帮助读者做哪个判断”。

## 数模专用补充

数模论文常把“模型结构图”“算法流程图”和“结果图”混在一张图里。默认拆开：结构图解释对象与关系，流程图解释计算步骤，结果图展示数据证据；只有三者确实形成一个读者任务时才合并，并在面板标题中区分角色。

题目中的时间窗口、容量上限、几何边界、禁行区、资源约束、评价指标和方案编号应优先成为坐标、边界、分组或标记，而不是被翻译成泛化的装饰性术语。
